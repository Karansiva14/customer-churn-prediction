# 📊 Customer Churn Analysis — Telecom Industry

## Overview
ML pipeline to predict customer churn using 5,000 telecom records.
Achieved high accuracy using ensemble models with SHAP explainability.

## Tech Stack
Python | Scikit-learn | Pandas | Seaborn | Matplotlib | SHAP | SciPy

## Key Features
- Exploratory Data Analysis (EDA) with visual insights
- Feature Engineering & Label Encoding
- Model Training with GridSearchCV tuning
- SHAP values for model explainability
- ROC-AUC evaluation metrics

## Dataset
Synthetic telecom dataset — 5,000 records
Features: Age, Tenure, Service Type, Monthly Spend, Complaints, Churn
